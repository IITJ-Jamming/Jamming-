## 🌙 What is this?

Someone on the IIT Jodhpur campus is *always* awake and making noise at 2 AM. **IITJ Jamming** is a real-time, campus-wide jam board that helps night-owls find each other — whether it's a spontaneous guitar session, a beatbox circle, or someone just vibing with a speaker.

## ✨ Features

- **🔴 Live jams** — See who's jamming right now, auto-refreshing, posts expire after 6 hours
- **📅 Schedule a jam** — Plan ahead and let campus know what's coming
- **📍 Campus spots** — Tap a known spot (Knowledge Tree, Fountain, Shamiyana, etc.) to start a jam there
- **🗺️ Live campus map** — Dark map view & illustrated map, with pulsing pins for active jams
- **🎨 Vibe tags** — Tag your jam as "no cap 🧢", "certified bop 🎧", "lowkey iconic ✨", and more
- **📸 Optional photos** — Add a photo to your jam post

## 🛠️ Tech

Built as a lightweight single-page web app (`index.html`) hosted via GitHub Pages.
